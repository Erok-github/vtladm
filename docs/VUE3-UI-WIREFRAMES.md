## 符号说明

```
┌──────────────┐  实线框 = 组件/卡片
│ 组件名称     │
└──────────────┘

┌ ╌ ╌ ╌ ╌ ╌ ╌ ┐  虚线框 = 可折叠区域
╎ 可折叠      │
└ ╌ ╌ ╌ ╌ ╌ ╌ ┘

[按钮]           按钮
[v 下拉选择]     下拉选择器
[✓ 复选框]       复选框
(...)            输入框
●                选中态
○                未选中态
────────────────  分隔线
════════════════  高亮/漂移标记
```
