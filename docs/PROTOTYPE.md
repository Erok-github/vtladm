## 1. 设计总览

### 1.1 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Vue 3.5+ (Composition API + `<script setup>`) |
| 语言 | TypeScript 5.x (strict mode) |
| 构建 | Vite 6 |
| UI 库 | Naive UI 2.x |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 (History 模式) |
| CSS | Naive UI 内置 + scoped style |

### 1.2 设计原则

- **数据驱动**：所有操作通过 API 完成，无整页刷新
- **即时反馈**：操作结果通过 Toast 通知，错误有重试选项
- **安全优先**：危险操作二次确认（NPopconfirm），iSCSI 执行设独立安全闸门
- **渐进展示**：仪表盘→库列表→库详情的层层下钻导航
- **响应式**：最小支持 1024px 宽度，侧栏可折叠

### 1.3 配色与主题

- 主题：Naive UI 亮色主题（默认）
- 语言：简体中文（NConfigProvider zhCN）
- 功能色：成功 #18a058 / 警告 #f0a020 / 错误 #d03050 / 信息 #2080f0

## 4. 全局框架

### 4.1 AppLayout — 主布局

```
┌──────────────────────────────────────────────────────────────┐
│ ┌──────────┐ ┌─────────────────────────────────────────────┐ │
│ │          │ │ TopBar                            [admin ▼] │ │
│ │ SideNav  │ ├─────────────────────────────────────────────┤ │
│ │          │ │                                             │ │
│ │ 240px    │ │         <router-view />                     │ │
│ │          │ │         (页面内容区)                          │ │
│ │          │ │                                             │ │
│ └──────────┘ └─────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

**SideNav 组件：**
- Logo + 标题："VTL 虚拟磁带库控制台"
- 菜单项：
  - 仪表盘（图标: Dashboard，路由 `/`）
  - 磁带库（分组，可展开）→ 库管理（路由 `/libraries`）
  - 账户安全（图标: Shield，路由 `/account`）
- 当前路由高亮（根据 `route.path` 前缀匹配）
- 底部：版本号

**TopBar 组件：**
- 左侧：库选择器（NSelect），选项来自 `libraryStore.onlineLibraries`
  - 切换库时调用 `window.location.reload()` 硬刷新
- 右侧：登录状态标签 + 登出按钮（NButton）

### 4.2 响应式行为

| 屏幕宽度 | 侧栏宽度 | 说明 |
|---|---|---|
| ≥ 1024px | 240px | 完整侧栏 |
| < 1024px | 64px | 仅图标，折叠文字 |

## 5. 页面详细设计

### 5.1 LoginView — 登录页

**路由**：`/login`（公开）

**布局**：居中卡片
```
┌─────────────────────────────────────────┐
│                                         │
│         ┌──────────────────────┐        │
│         │   VTL 虚拟磁带库控制台  │        │
│         │                      │        │
│         │  用户名: [admin]     │        │
│         │  密码:   [________]  │        │
│         │                      │        │
│         │  验证码:  3 + 7 = ?  │        │
│         │  答案:   [____]      │        │
│         │                      │        │
│         │  [      登 录     ]  │        │
│         │                      │        │
│         └──────────────────────┘        │
│                                         │
└─────────────────────────────────────────┘
```

**交互状态：**

| 状态 | 表现 |
|---|---|
| 初始加载 | 检查会话，已登录则跳转 `/`，否则加载验证码 |
| 输入中 | 密码框 `type="password"`，验证码显示算术题 |
| 登录中 | 按钮 loading 状态 + 禁用 |
| 登录失败 | Toast 错误提示 + 自动刷新验证码 |
| 登录成功 | 跳转至 `redirect` 参数指定路径或 `/` |
| 需改密码 | 跳转至 `/account` |

**API 调用：**
- `GET /api/session/ping`（检查已登录）
- `GET /api/captcha`（获取验证码）
- `POST /api/login`（提交登录）

**统计卡片：** 使用 NGrid + NGi + NCard，响应式布局（4列→2列→1列）

**巡检结果：** ok=绿色 NTag、warn=橙色 NTag、crit=红色 NTag

**操作日志：** NDataTable 简化版，列：时间、操作、详情

**自动刷新：** 每 30 秒轮询一次 `fetchStatus`、`fetchSystemSnapshot`

**API 调用：**
- `GET /api/libraries`
- `GET /api/libraries-status`
- `GET /api/patrol`
- `GET /api/fabric`
- `GET /api/monitor/system`
- `GET /api/monitor/capacity-trend`
- `GET /api/monitor/events`

## 6. 通用组件规范

### 6.1 确认对话框（NPopconfirm）

触发条件：删除磁带/库/货架、清空磁带、撤销会话等不可逆操作

```
┌──────────────────────────────┐

└──────────────────────────────┘
```

### 6.2 Toast 通知（useMessage）

| 类型 | 颜色 | 图标 | 持续时间 | 操作 |
|---|---|---|---|---|
| 成功 | 绿色 | checkmark | 3 秒 | 无 |
| 错误 | 红色 | close | 5 秒 | 重试按钮（如适用） |
| 警告 | 橙色 | warning | 4 秒 | 无 |
| 信息 | 蓝色 | info | 3 秒 | 无 |

### 6.3 Loading 状态（NSpin）

- 全页面加载：居中大号 Spin
- 表格加载：表格区域覆盖 Spin
- 按钮加载：按钮内置 loading 属性

### 6.4 空状态

- 磁带库列表为空：NEmpty + "暂无磁带库" + [新建磁带库] 按钮
- 磁带列表为空：NEmpty + "暂无磁带，请先创建磁带"
- 漂移列表为空：NEmpty + "未发现漂移，DB 与内核状态一致"

### 6.5 错误状态

- API 请求失败：Toast 错误消息（含后端返回的 error 文本）
- 401 未认证：自动跳转 `/login`
- 网络错误：Toast "网络连接失败，请检查服务状态" + 重试按钮

## 7. 交互状态与反馈

### 7.1 操作生命周期

```
触发操作
  │
  ▼
[按钮 loading + 禁用所有输入]
  │
  ├── 成功 ──▶ [Toast 成功] ──▶ [刷新数据]
  │
  └── 失败 ──▶ [Toast 错误 + reason] ──▶ [恢复按钮]
```

### 7.2 表单校验时机

| 时机 | 行为 |
|---|---|
| 输入时 (input) | 实时显示格式错误（红色边框+提示文字） |
| 失焦时 (blur) | 触发服务端不可见的本地校验 |
| 提交时 (submit) | 全部字段校验，阻止提交并聚焦第一个错误字段 |

### 7.3 并发操作保护

- 提交按钮在请求进行中禁用（loading 状态）
- 不允许重复提交同一表单
- 批量操作时全成功或全失败（事务性）
